Parte 1 • Prueba t de Student (1/3)

¿Qué evalúa la Prueba t en Regresión Múltiple?

Significancia Individual de cada variable

En el modelo $\hat{Y} = \hat{\beta}_0 + \hat{\beta}_1 X_1 + \dots + \hat{\beta}_k X_k$, la prueba $t$ verifica si una variable $X_j$ realmente influye en $Y$ o si su coeficiente $\hat{\beta}_j \neq 0$ se debe solo al azar muestral.

Regla de oro: Ceteris Paribus

Evalúa el aporte propio de $X_j$ manteniendo constantes todas las demás variables del modelo.

Idea clave: Una variable puede parecer importante por sí sola, pero perder significancia cuando otra variable del modelo ya explica ese mismo efecto.

Planteamiento de Hipótesis para $\beta_j$

Hipótesis Nula ($H_0$) Sin efecto
$$H_0: \beta_j = 0$$

La variable $X_j$ no aporta linealmente a $Y$ (dadas las demás variables).

Hipótesis Alternativa ($H_1$) Con efecto
$$H_1: \beta_j \neq 0$$

La variable $X_j$ sí aporta significativamente a explicar $Y$.

Parte 1 • Prueba t de Student (2/3)

Fórmula Señal vs. Ruido y Criterio de Rechazo

Gráfica interactiva
$$t_{\text{calc}} = \frac{\hat{\beta}_j}{EE(\hat{\beta}_j)}$$
Numerador: Señal ($\hat{\beta}_j$)  |  Denominador: Ruido ($EE$)
Grados de libertad: $gl = n - k - 1$

Se usa la distribución $t$-Student porque no conocemos $\sigma^2$ y la estimamos con los datos ($n$: muestra, $k$: variables).

¿Cuándo rechazamos $H_0$?
  • Si $|t_{\text{calc}}| > t_{\text{crítico}}$ (cae en las colas rojas).
  • O de forma práctica: si $p\text{-valor} < \alpha$ (ej. $0.05$).

Parte 1 • Prueba t de Student (3/3)

3 Puntos Clave

1

No significancia $\neq$ efecto cero

Si $p > 0.05$, puede deberse a una muestra pequeña o a multicolinealidad (variables redundantes que inflan el Error Estándar).

2

Significancia $\neq$ relevancia práctica

Con muestras muy grandes, efectos diminutos pueden salir estadísticamente significativos. Siempre hay que revisar la magnitud real de $\hat{\beta}_j$.

3

Evalúa de una en una

La prueba $t$ analiza cada variable por separado. No evalúa si todo el modelo funciona en conjunto.

Parte 2 • Prueba F de Fisher–Snedecor (2/6)

¿Qué es la Prueba F?

Permite evaluar si las variables explicativas aportan información al modelo en conjunto.

En una regresión múltiple, la prueba $F$ contrasta si todos los coeficientes de pendiente son iguales a cero.

Responde una pregunta central:

¿El modelo explica $Y$ mejor que uno con solo intercepto?

Relación representada de manera conceptual
Parte 2 • Prueba F de Fisher–Snedecor (3/6)

Hipótesis de la Prueba F

Para un modelo con $k$ variables independientes.

Hipótesis Nula ($H_0$)
$$H_0 : \beta_1 = \beta_2 = \dots = \beta_k = 0$$

Ninguna pendiente aporta explicación lineal.

Hipótesis Alternativa ($H_1$)
$$H_1 : \text{al menos un } \beta_j \neq 0$$

Alguna variable tiene un efecto lineal parcial.

La prueba $F$ es siempre de cola derecha.
Parte 2 • Prueba F de Fisher–Snedecor (4/6)

¿Cómo se calcula el Estadístico F?

Se compara la variación que explica el modelo con la variación residual.

$$F = \frac{SC_{\text{regresión}} / k}{SC_{\text{error}} / (n - k - 1)}$$
$$F = \frac{R^2 / k}{(1 - R^2) / (n - k - 1)}$$
Bajo $H_0$: grados de libertad $(k,\; n - k - 1)$
$n$ = número de observaciones
$k$ = número de predictores
$R^2$ = proporción de varianza explicada

Parte 2 • Prueba F de Fisher–Snedecor (5/6)

¿Cómo se interpreta?

La decisión se toma a partir del valor $p$ o comparando $F$ calculada y $F$ crítica.

Si $p < 0.05$
Se rechaza $H_0$.

El conjunto de variables explica una proporción estadísticamente significativa de la variabilidad de $Y$.

Si $p \geq 0.05$
No se rechaza $H_0$.

No hay evidencia suficiente de significancia global al nivel elegido.

Importante: significancia estadística no implica causalidad ni garantiza buena capacidad predictiva.
Parte 2 • Prueba F de Fisher–Snedecor (6/6)

Condiciones y Uso Responsable

Antes de interpretar $F$, conviene verificar la adecuación del modelo.

Linealidad: Relación lineal entre predictores y media de $Y$.
Independencia: Observaciones y errores independientes según el diseño.
Homocedasticidad: Varianza aproximadamente constante de los errores.
Normalidad de errores: Relevante para la inferencia $F$ exacta en muestras pequeñas.
La prueba $F$ evalúa el modelo completo; la prueba $t$ evalúa cada coeficiente por separado.
Referencia: Advanced Statistics using R, “Multiple linear regression” (advstats.psychstat.org/book/mregression/).
